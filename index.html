# 🐍 PyPath — Платформа для изучения Python Полноценная веб-платформа для изучения Python с нуля до продвинутого уровня. ## 📦 Стек технологий | Часть | Технология | |-------|-----------| | Frontend | Next.js 14, TypeScript, Tailwind CSS | | Редактор кода | Monaco Editor (как VS Code) | | Backend | FastAPI (Python) | | База данных | SQLite | | AI Наставник | Anthropic Claude API | | Состояние | Zustand | --- ## 🚀 Быстрый запуск ### Требования - Node.js 18+ - Python 3.10+ - npm или pnpm --- ### 1. Клонируй / распакуй проект ```bash cd pypath ``` --- ### 2. Запуск Backend (FastAPI) ```bash cd backend # Создай виртуальное окружение python -m venv venv source venv/bin/activate # Mac/Linux # или: venv\Scripts\activate # Windows # Установи зависимости pip install -r requirements.txt # (Опционально) Добавь API ключ для AI-наставника export ANTHROPIC_API_KEY="sk-ant-..." # Mac/Linux # set ANTHROPIC_API_KEY=sk-ant-... # Windows # Запусти сервер uvicorn main:app --reload --port 8000 ``` Backend запустится на: **http://localhost:8000** Документация API: **http://localhost:8000/docs** --- ### 3. Запуск Frontend (Next.js) Открой **новый терминал**: ```bash cd frontend # Установи зависимости npm install # Запусти dev-сервер npm run dev ``` Frontend запустится на: **http://localhost:3000** --- ## 🎮 Что доступно ### Страницы | URL | Описание | |-----|----------| | `/` | Лендинг страница | | `/demo` | Демо редактор (без регистрации) | | `/auth/register` | Регистрация | | `/auth/login` | Вход | | `/dashboard` | Главная панель | | `/learn` | Все модули курса | | `/learn/[module]` | Уроки модуля | | `/learn/[module]/[lesson]` | Урок с редактором | | `/quest` | Игровой режим Квест | | `/practice` | Свободный редактор | --- ## 📚 Модули курса 1. 🚀 **Введение** — print(), первые программы 2. 📦 **Переменные** — создание, операции 3. 🔢 **Типы данных** — int, float, str, bool 4. 🔀 **Условия** — if/elif/else 5. 🔄 **Циклы** — for, while, range() 6. 📋 **Списки** — создание, методы, срезы 7. ⚙️ **Функции** — def, параметры, return 8. 🏗️ **ООП** — классы, методы, наследование --- ## 🎮 Режим Квест 5 игровых уровней: - 🤖 Уровень 1: Помоги роботу (print) - 🔐 Уровень 2: Взломай замок (циклы) - 🚀 Уровень 3: Космический корабль (условия) - 🏦 Уровень 4: Банк будущего (функции) - 🧬 Уровень 5: Биоморф (ООП) --- ## 🤖 AI-наставник Без API ключа — умные заготовленные ответы. С ключом Anthropic — полноценный Claude. ```bash export ANTHROPIC_API_KEY="sk-ant-api03-..." ``` --- ## 🗂 Структура проекта ``` pypath/ ├── backend/ │ ├── main.py # FastAPI приложение │ ├── database.py # SQLite setup │ ├── requirements.txt │ ├── routers/ │ │ ├── auth.py # Аутентификация │ │ ├── code_runner.py # Запуск Python кода │ │ ├── lessons.py # Уроки │ │ ├── progress.py # Прогресс пользователя │ │ └── ai_mentor.py # AI чат │ └── data/ │ ├── lessons_data.py # Все уроки и модули │ └── lesson_tests.py # Тесты для проверки │ └── frontend/ ├── src/ │ ├── app/ │ │ ├── page.tsx # Лендинг │ │ ├── dashboard/ # Главная │ │ ├── auth/ # Вход/Регистрация │ │ ├── learn/ # Курс │ │ ├── quest/ # Квест │ │ ├── practice/ # Редактор │ │ └── demo/ # Демо │ ├── components/ │ │ └── Navbar.tsx │ ├── lib/api.ts # API клиент │ ├── store/index.ts # Zustand store │ └── types/index.ts # TypeScript типы ├── package.json ├── tailwind.config.ts └── next.config.js ``` --- ## 🔧 Расширение проекта ### Добавить урок В `backend/data/lessons_data.py` добавь объект урока в нужный модуль. ### Добавить квест-уровень В `frontend/src/app/quest/page.tsx` добавь в массив `QUEST_LEVELS`. ### Добавить модуль В `backend/data/lessons_data.py` добавь новый объект в массив `MODULES`. --- ## 🌐 Production деплой **Backend на Railway/Render:** ```bash # Procfile web: uvicorn main:app --host 0.0.0.0 --port $PORT ``` **Frontend на Vercel:** ```bash vercel --prod # Добавь переменную NEXT_PUBLIC_API_URL=https://your-backend.railway.app ``` --- ## 📝 Заметки по безопасности - Запуск кода изолирован (subprocess с timeout 5 сек) - Запрещены опасные импорты (os, sys, subprocess, socket) - В production рекомендуется Docker-изоляция или AWS Lambda для запуска кода --- Создано с ❤️ для изучения Python
